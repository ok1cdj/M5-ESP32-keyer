Install CW keyer firmwareNahraj firmware klíčovače

CW keyer for the M5Stack Atom family. Send it text over Bluetooth LE, HTTP or cwdaemon and it keys the radio through an optocoupler or a MOSFET; with an Icom it also reads the frequency over CI-V. Flash it straight from this page, no IDE and no drivers needed. CW klíčovač pro desky M5Stack Atom. Pošli mu text přes Bluetooth LE, HTTP nebo cwdaemon a on klíčuje rádio přes optočlen nebo MOSFET; s Icomem čte přes CI-V i kmitočet. Firmware nahraješ přímo z téhle stránky, bez IDE a bez ovladačů.

Before you connectNež připojíš

  • Browser: Chrome or Edge on a desktop or laptop. The flasher uses Web Serial, which Safari, Firefox and phones or tablets don't support.
  • Prohlížeč: Chrome nebo Edge na počítači. Flasher používá Web Serial, který Safari, Firefox ani telefony a tablety neumí.
  • Cable: a USB-C cable that carries data, not a charge-only one.
  • Kabel: USB-C kabel, který přenáší data, ne jen nabíjecí.
  • AtomS3 / AtomS3 Lite: enter bootloader mode first. Hold the reset button on the side for about 2 seconds, until the green LED inside lights up.
  • AtomS3 / AtomS3 Lite: nejdřív přepni do bootloaderu. Podrž tlačítko reset na boku asi 2 sekundy, dokud se uvnitř nerozsvítí zelená LED.
  • Atom Lite: no button needed. The USB bridge resets the board by itself.
  • Atom Lite: tlačítko netřeba. USB převodník desku resetuje sám.

After flashingPo nahrání

  1. The board starts in BLE mode, and the LED shows blue for 2 seconds.
  2. Deska se spustí v režimu BLE a LED na 2 sekundy svítí modře.
  3. Connect with kQSO or nRF Connect to keyer-XXXX and send SEND CQ CQ DE ....
  4. Připoj se z kQSO nebo nRF Connect ke keyer-XXXX a pošli SEND CQ CQ DE ....
  5. To switch mode, hold the button while powering on. When the LED shows the mode you want (blue BLE, green HTTP, yellow CWD), release it.
  6. Režim přepneš tak, že při zapnutí držíš tlačítko. Až LED ukáže požadovaný režim (modrá BLE, zelená HTTP, žlutá CWD), pusť ho.
  7. For the HTTP and CWD modes, set up Wi-Fi below. The keyer then appears on the network as keyer-XXXX.local.
  8. Pro režimy HTTP a CWD nastav Wi-Fi níže. Klíčovač se pak v síti objeví jako keyer-XXXX.local.

Configure over BluetoothNastavení přes Bluetooth

The keyer must be in BLE mode (blue LED at start). This part works in Chrome and Edge on a desktop and in Chrome on Android. On Linux you may have to enable Web Bluetooth at chrome://flags/#enable-web-bluetooth. iPhone and iPad don't have Web Bluetooth: use nRF Connect there. Klíčovač musí být v režimu BLE (při startu modrá LED). Tahle část funguje v Chrome a Edge na počítači a v Chrome na Androidu. Na Linuxu může být potřeba zapnout Web Bluetooth v chrome://flags/#enable-web-bluetooth. iPhone a iPad Web Bluetooth nemají: tam použij nRF Connect.
