OK1CDJ / M5-ESP32-keyer

Install CW keyer firmware

CW keyer for the M5Stack Atom family. Send it text over Bluetooth LE, HTTP or cwdaemon and it keys the radio through an optocoupler or a MOSFET. Flash it straight from this page, no IDE and no drivers needed.

Before you connect

  • Browser: Chrome or Edge on a desktop or laptop. The flasher uses Web Serial, which Safari, Firefox and phones or tablets don't support.
  • Cable: a USB-C cable that carries data, not a charge-only one.
  • AtomS3 / AtomS3 Lite: enter bootloader mode first. Hold the reset button on the side for about 2 seconds, until the green LED inside lights up.
  • Atom Lite: no button needed. The USB bridge resets the board by itself.

Connect & flash

Atom Lite / AtomS3 Lite

This browser can't flash over USB. Open this page in Chrome or Edge on a computer. The browser allows a USB connection only when this page is loaded over HTTPS.

The flasher detects the chip (ESP32 or ESP32-S3) and writes the matching build.

AtomS3 (with display)

This browser can't flash over USB. Open this page in Chrome or Edge on a computer. The browser allows a USB connection only when this page is loaded over HTTPS.

AtomS3 has the same chip as AtomS3 Lite, so the flasher can't tell the two apart. Use this button only for the AtomS3 with the screen.

After flashing

  1. The board starts in BLE mode, and the LED shows blue for 2 seconds.
  2. Connect with kQSO or nRF Connect to keyer-XXXX and send SEND CQ CQ DE ....
  3. To switch mode, hold the button while powering on. When the LED shows the mode you want (blue BLE, green HTTP, yellow CWD), release it.
  4. For the HTTP and CWD modes, set up Wi-Fi below. The keyer then appears on the network as keyer-XXXX.local.

Configure over Bluetooth

The keyer must be in BLE mode (blue LED at start). This part works in Chrome and Edge on a desktop and in Chrome on Android. On Linux you may have to enable Web Bluetooth at chrome://flags/#enable-web-bluetooth. iPhone and iPad don't have Web Bluetooth: use nRF Connect there.
